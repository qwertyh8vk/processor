# 1. Основные сведения

Этот проект представляет из себя попытку в виртуальный процессор (алгоритмически полный)

Работа процессора состоит из 3-ёх основных актов

(1) - Генерация служебных файлов для ассемблера (см. пункт 3 сборка и запуск)

(2) - Перевод кода в набор машинных команд с помощью ассемблера

(3) - Рабочий цикл процессора (исполнение машинных инструкций)

# 2. Вычислительная полнота

Процессор считается **алгоритмически полным**, если на нём можно реализовать какую-либо универсальную вычислительную модель. 
То есть: если у него достаточно памяти и времени, он способен выполнить любую вычислимую задачу.

Как это связано с архитектурой:

(1) - **Условные переходы и циклы** (Без них нельзя реализовать произвольные алгоритмы)

(2) - **Доступ к произвольной ячейке памяти** (Адресная память)

(3) - **Базовые операции** - арифметика (Этого хватает, чтобы собрать любую логику)

(4) - **Возможность эмуляции** (На любом современном процессоре можно эмулировать другую машину Тьюринга или даже другой процессор)

# 3.1. Требования и сборка + запуск

Для запуска программы потребуется компилятор языка **C/C++** (Автор репозитория использует компилятор g++)

Все соответствующие файлы типа *.h и *.cpp следует расположить в одной папке.

В этой же папке вам следует работать с asm'овскими исходниками (расширение .txt) Примеры исходников см. в пункте 4.

После этого потребуется ввести несколько команд в терминале:

Компиляция актуальных enum'ов, хэшей для регистров и команд
``` bash
g++ enum_generator.cpp enum_djb.cpp -o enum_gen
```

Запуск генератора
``` bash
./enum_gen
```

Компиляция asm'а
``` bash
g++ assembler.cpp enum_djb.cpp -o assembler
```

Запуск asm'а
``` bash
./assembler
```
! На этом этапе должен у вас сформируется файл ваше_название.bin - это файл с бинарным кодом, с которым как раз и должен работать процессор

Если требуется посмотреть содержимое bin-файла, советую делать это через hex-редактор (В случае если вы работаете в VSCode, рекомендую расширение Hex Editor от Microsoft)

Компиляция процессора
``` bash
g++ processor.cpp stack_v3.cpp -o procik
```
! Обратить внимание на флаги, их нужно указывать для корректной работы raylib

Запуск процессора
``` bash
./procik
```
